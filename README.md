Student Management System
A simple web-based Student Management System using HTML, CSS, and JavaScript.
This project allows for secure and fast registration of students and teachers, automatically generating unique IDs and secure passwords. It saves all records locally in the browser using localStorage.
✨ Features
Student Registration:
Fill out student details (name, email, class, DOB, gender).
Automatically generates a unique student ID and a random strong password.
Teacher Registration:
Fill out teacher details (name, email, subject, phone, password).
Automatically generates a unique teacher ID.

Password confirmation with validation.
Records Viewer:
See all registered students and teachers in a separate view.
Ability to delete any record.
Local Persistence:
Data stored in the browser (localStorage); persists across reloads.
Responsive Design:
Optimized for desktops, tablets, and mobile devices.
Form Validation:
Built-in validation for all fields (required, email, phone, password strength, etc.).

🛡️ Security Notes
All passwords are generated securely, but they are stored in plain text for demo/learning purposes.
For real applications, always hash passwords and use a backend.

Data is stored locally in your browser; it is not shared across browsers or users.

💡 Customization
Add new classes or subjects in the HTML as needed.

Change the ID format or password length in script.js.

Adjust validation as per your institute's needs.
